# Brief To Backlog

## Purpose

Convert a vague request into an execution-ready first slice without pretending unknowns are already resolved.

## Process

1. Restate the requested outcome in plain language.
2. Separate facts, assumptions, and missing information.
3. Define success criteria and non-goals.
4. Propose the smallest useful first implementation slice.
5. Call out delivery, stakeholder, and technical risks.

## Output Contract

Return:

- concise problem framing
- implementation goals
- open questions
- recommended first slice
- risk notes
