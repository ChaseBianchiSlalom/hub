# AI Feature Delivery

## Outcome

Provide a repeatable path from AI-related feature request to implementation-ready delivery plan.

## Components

- `engagement-intake`
- `brief-to-backlog`
- `solution-architect`
- `repo-kickoff`
- `repo-onboarding`
- `implementation-lead`
- `delivery-risk-scan`

## Activation

Use this playbook when the team needs to move from a feature brief to a concrete delivery path inside an existing product or codebase.

## Success Condition

The team leaves the workflow with a scoped first slice, clear likely change points, and explicit delivery risks.
